# Portfolio Requirements

## Objective
Create a single-page personal portfolio as a static HTML page for a developer profile. The page must be lightweight, mobile-friendly, and fully self-contained in one file without any framework, build step, or JavaScript.

## Content Requirements
- Include the person's full name.
- Include a one-line role statement.
- Include exactly three project cards.
- Each project card must contain:
  - a title
  - a one-sentence description
  - a link
- Include contact links for:
  - email
  - GitHub
  - LinkedIn

## Technical Constraints
- Use a single static `index.html` file.
- Include all CSS in an inline `<style>` block.
- Content must be written directly in the HTML.
- No external frameworks, libraries, or build tools.
- No backend integration.
- No JavaScript at all.
- The page must work on a phone and use responsive layout behavior.

## Layout Requirements
- Header with the name and role.
- Three project cards beneath the header.
- Footer with the contact links.
- Keep the overall page to one screen on desktop and comfortable on mobile.

## Visual Requirements
- Dark background.
- One accent colour used consistently.
- Generous spacing between sections and content blocks.
- Clean, readable typography.
- Strong contrast for accessibility.

## Output Expectations
- Deliver a polished, minimal single-page portfolio.
- Keep the structure simple and maintainable.
- Ensure the page renders correctly without any network dependency for the styling or script.
